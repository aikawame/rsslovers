# RSS愛好会

## 概要

[RSS愛好会](https://rss.wor.jp/) は、新聞社等のサイトでRSSフィードが配信されていない場合に代わりにフィード配信を行うためのサービスです。

ウェブサイトのフロントエンド、クローラー、マスターデータの3つに大きく機能分割されています。

### フロントエンド

RSS愛好会のウェブサイト本体です。

- 言語: TypeScript 7.0
- フレームワーク: Next.js 16.x
- Linter: Biome
- CI: GitHub Actions 
- 実行基盤: Vercel

### クローラー

フィードを各外部サイトから収集・生成し、クラウドストレージにアップロードするクローラーです。

- 言語: Ruby 4.0
- フレームワーク: Ruby on Rails 8.1
- テスト: RSpec
- Linter: RuboCop
- CI: GitHub Actions
- 実行基盤: GitHub Actions
- ストレージ: Amazon S3

### マスターデータ

フィードおよびそのカテゴリー・サイトの管理データです。

- 形式: YAML
- バージョン管理: Git / GitHub

## コントリビュート

### 手順

1. ソースコードを [フォーク](https://github.com/aikawame/rsslovers/fork) します。
2. ブランチを切ります。 ( `git checkout -b feature/hogehoge` )
3. 変更をコミットします。 ( `git commit -am '何やらを追加する'` )
4. ブランチをプッシュします。 ( `git push origin feature/hogehoge` )
5. プルリクエストを作成します。

### コミット

- コミットメッセージは「○○する」といった動詞で記述してください。

### テスト

現在はRuboCopおよびBiomeによるコーディングスタイルの検証と、各種クローラーのテストを行っています。  
クローラーの追加時には、対応するテストも追加する必要があります。

### プルリクエスト

`main` ブランチに対して行ってください。  
その際、改修対象機能群のテストを全て通過する必要があります。

### デプロイ

プルリクエストがマージされた際に、変更対象に応じたCI/CDが自動的に実行されます。
